# Task guides

Each guide takes one job from start to finish, with complete code, the decisions you'll face, and what can go wrong. The examples use Node.js, with Python and Go where the difference matters; every method exists in all five server SDKs.

| Guide | You'll learn |
| --- | --- |
| [Store values at the source](/developers/recipes/store-values/) | Where to tokenize, choosing token kinds, `subject_ref`, migrating an existing database |
| [Reveal values safely](/developers/recipes/reveal-values/) | Purposes, decisions, asking for less, caching, showing values in your UI |
| [Find a customer by value](/developers/recipes/find-by-value/) | Duplicate checks and sign-in by email without decrypting, and the rate limit |
| [Data subject requests](/developers/recipes/data-subject-requests/) | Access, erasure and restriction requests end to end |
| [Decide without moving data](/developers/recipes/resident-checks/) | Age, name and amount checks answered in the country |
| [Protect free text](/developers/recipes/detect-in-text/) | Support messages, notes and documents: find and tokenize identifiers |
| [Cloak text for AI](/developers/recipes/cloak-for-ai/) | Send prompts to a model abroad and restore its replies |
| [Collect and reveal in the front end](/developers/recipes/collect-and-reveal/) | Secure forms and reveals on web and mobile, server and client |
| [Check data leaving the country](/developers/recipes/flow-checks/) | Report what a nightly export holds, and block it when it isn't clean |
| [Test safely](/developers/recipes/test-safely/) | Test vaults, dry runs, made-up values for every data type, CI |
| [Retries and errors](/developers/recipes/retries-and-errors/) | Every error code, what's safe to retry, idempotency |
