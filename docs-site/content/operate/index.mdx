# Run it yourself

Onshore ships as containers. Every edition, including Onshore Cloud, runs the same ones.

| Service | Does | Compose profile |
| --- | --- | --- |
| `edge` (Caddy) | TLS, routing, security headers | always |
| `vault-api` | Data API, detection, access rules, audit chain | always |
| `control-api` | Configuration, people, reports, webhooks | always |
| `console` | The web console | always |
| `postgres` | Database (values encrypted) | always |
| `keys` (OpenBao) | Key service holding the master key | always |
| `log-processor` | Log redaction | `logs` |
| `ai-gateway` | AI gateway | `ai` |
| `http-proxy` | HTTP proxy | `proxy` |
| `adapters` | Support tool adapters | `adapters` |
| `file-redactor` | PDFs, images, audio | `files` |
| `tools` | `rv`, migrations | `tools` |
