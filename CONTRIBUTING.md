# Contributing to Onshore

Thank you for helping. Before your first pull request can be merged, you need to accept the [Contributor Licence Agreement](CLA.md). A check on the pull request asks you to; reply with the comment it shows. You only do this once.

The agreement lets Flowsplus Services, which owns Onshore, ship your contribution in both the open source (AGPL) and commercial editions. You keep the copyright in your work.

- Code outside `ee/` is AGPL-3.0. Code in `ee/` is under the [Onshore Commercial Licence](ee/LICENSE).
- Report security problems privately through the repository's **Security** tab (Report a vulnerability), never in a public issue.
- Use of the Onshore name and logo is covered by the [trademark policy](TRADEMARKS.md).
